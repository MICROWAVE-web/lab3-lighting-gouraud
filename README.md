# Лабораторная работа 3 — освещённость и закраска Гуро

Построение сцен с простейшей моделью освещённости.
Фигура вращения, триангуляция, flat / Гуро, движение камеры A↔B.

Без OpenGL / NumPy — только стандартная библиотека Python (`tkinter`, `math`).

## Запуск

```bash
./run.sh
# или
/usr/local/bin/python3 main.py
```

## Управление

| Клавиша | Действие |
|---------|----------|
| Пробел | Старт/стоп движения камеры между двумя точками |
| G | Переключение Гуро ↔ flat |
| R | Вращение объекта |
| `]` / `[` | Больше / меньше секторов триангуляции |
| Esc | Выход |

## Что реализовано

1. **Фигура вращения** — профиль-кривая в плоскости `(r, z)`, вращение вокруг Z (`revolution.py`).
2. **Триангуляция** — сетка профиль × сектора, 2 треугольника на ячейку.
3. **Освещение** — `I = Ia·ka + Id·kd·max(0, n·L)`, палитра grayscale (`lighting.py`).
4. **Камера** — плавный путь между точками A и B (`look_at` + lerp).
5. **Гуро** — интенсивность в вершинах, интерполяция по треугольнику + z-буфер (`raster.py`).

## Файлы

| Файл | Назначение |
|------|------------|
| `revolution.py` | Профиль, меш, нормали вершин |
| `lighting.py` | Модель Ламберта, grayscale |
| `raster.py` | Z-буфер, заливка flat/Gouraud |
| `math3d.py` | Матрицы, look_at, проекция |
| `main.py` | UI и цикл отрисовки |
